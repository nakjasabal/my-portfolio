# Codex CLI 무료 사용량 정리

> 확인일: 2026-08-31  
> 대상: **ChatGPT Free 계정으로 로그인한 Codex CLI**. API 키를 사용하는 경우에는 별도의 API 과금·레이트 리밋이 적용된다.

## 결론

- Codex CLI는 ChatGPT **Free 플랜에 포함**되어 있으며, OpenAI는 무료 플랜을 “짧은 코딩 작업을 위한 체험” 용도로 안내한다.
- 다만 OpenAI 공식 문서에는 Free 플랜의 **하루 메시지 수, 토큰 수, 정확한 초기화 시각**이 공개되어 있지 않다. 따라서 “하루 N회”처럼 고정된 수치로 말할 수 없다.
- 사용량은 작업의 모델, 규모·복잡도, 대화 문맥 길이, 도구 사용 등에 따라 달라진다. 같은 수의 프롬프트라도 소진량이 같지 않다.
- 문서에 명시된 공통 기준은 **5시간 롤링(rolling) 창**이며, 경우에 따라 **주간 한도**도 추가로 적용될 수 있다. 무료 플랜의 세부 한도·리셋은 계정·수요·지역·서비스 정책에 따라 표시되는 값이 기준이다.

## “하루에 얼마나?”에 대한 실무적 답

무료 플랜은 일일 정액 횟수로 운영된다고 공개되어 있지 않다. 짧고 범위가 작은 수정·질문은 여러 번 처리할 수 있지만, 큰 저장소 분석, 긴 에이전트 작업, 많은 파일·도구 호출이 포함된 요청은 적은 횟수로도 제한에 닿을 수 있다.

즉, **하루 사용 가능량을 미리 숫자로 보장할 수 없고**, 실제 남은 양은 계정의 사용량 화면 또는 CLI에서 확인해야 한다.

## 제한에 걸렸을 때 언제 다시 쓸 수 있나?

일반적인 사용 창은 **고정된 자정 리셋이 아니라 5시간 롤링 창**이다. 즉, 사용량이 한 번에 새로 채워지는 “매일 00:00” 방식이라고 가정하면 안 된다. 최근 사용분이 시간 창에서 빠져나가면 다시 사용할 수 있게 된다.

또한 주간 한도에 도달한 경우에는 5시간 창이 갱신되어도 계속 제한될 수 있다. 정확한 재개 시각은 제한 안내와 사용량 화면에 표시되는 계정별 정보를 확인하는 것이 가장 정확하다.

## 남은 사용량 확인 방법

| 위치 | 방법 |
| --- | --- |
| Codex CLI 실행 중 | `/status` 입력 — 남은 사용량을 확인 |
| 웹 | [Codex Usage Dashboard](https://chatgpt.com/codex/settings/usage)에서 현재 한도와 사용 현황 확인 |

제한 메시지가 나왔을 때는 `/status`를 먼저 실행해 어느 한도에 걸렸는지와 다음 이용 가능 시점을 확인한다.

## API 키 사용과의 차이

ChatGPT Free 로그인 기반 Codex와 API 키 기반 Codex는 다르다.

- **ChatGPT Free 로그인:** 제한된 Codex 사용량이 포함되지만, 공개된 고정 일일 수치는 없다.
- **API 키:** 사용량은 API 요금제로 별도 청구된다. 현재 Codex 모델의 API Free 티어는 지원되지 않으므로, 무료 API 호출량이 제공되는 것은 아니다.

## 한 줄 요약

Codex CLI 무료 사용량은 공개된 “하루 N회” 정액이 아니다. **짧은 작업 중심의 제한된 사용량**이며, 제한 후에는 주로 **5시간 롤링 창**을 기준으로 회복되고 주간 한도도 있을 수 있으므로, 실제 남은 양과 정확한 재개 시각은 `/status` 또는 Usage Dashboard에서 확인한다.
